# Planner 编排参考

权威来源：`../../../docs/04-roles.md`、`../../../docs/05-state-and-evidence.md`。本文件是执行摘要。

## 单层调度

- 只有当前 Run 的 Planner 创建正式块并调度角色。
- 需要角色时返回精确交接，由主会话发起同级调用；不派生角色链。
- 宿主主会话只转发，不是第二个 Planner。

## 交接必给

Run ID、块 label、单一角色动作、产物路径与对象修订、完整 SHA、适用 Finding/Defect ID、允许/受保护路径、输出契约、停止条件与预算。缺项 → 接收方 `BLOCKED`。

## 调查预算

调查默认一轮 + 一轮缺口补查；两次无新增事实停止同类搜索，继续调查须关联当前 AC/失败/约束。

## 熔断

5 分钟无可观察产物中断；30 分钟软检查点；轮次/上下文/解析失败不自动恢复累计会话。同一 Finding 第二次失败换全新会话 + 最小根因包。

## 复核者数量

STANDARD/HIGH_RISK 默认一名主独立复核者；第二名仅用户明确要求或主复核者发现需不同专业判断的 blocking 安全/架构问题。Advisory 转技术债。一轮 Findings 一个修复会话统一处理。
